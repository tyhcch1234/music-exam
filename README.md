# Music Exam · 音樂考試溫習

P3 音樂科的溫習網頁，把課堂教學影片（51 分鐘）整理成 **兩個單元、每單元三節課**。每節課先看學習重點，再做測試；測試即時對答案並講解，成績自動儲存在瀏覽器。

## 單元與課節

| 單元 | 課節 | 內容 |
| --- | --- | --- |
| 單元一 Music and Atmosphere | 第一課 | 大聲與細聲：力度 dynamics、forte / piano、《Sleep Baby Sleep》的 pp |
| | 第二課 | 二拍子 2/4 拍：拍號上下數字的意思、強—弱規律、《Pitter Patter》 |
| | 第三課 | 管弦樂團的樂器家族：木管、銅管、弦樂、敲擊 |
| 單元二 World Music | 第一課 | 唱名 solfège、《Yankee Doodle》、ostinato 固定音型、《綠袖子》 |
| | 第二課 | 二段體 A+B、四分休止符、延音記號 fermata、《The Riddle》 |
| | 第三課 | 三段體 A+B+A、弱起拍 anacrusis、《一閃一閃小星星》、《Home on the Range》 |

## 每節課的結構

1. **學習重點** — 課堂影片片段、樂譜／圖片（可點擊放大）、重點列表、音樂詞彙、聽一聽錄音。
2. **測試** — 六題，題型包括選擇、是非、填充、配對、排序、聆聽；作答後即時顯示答案與講解。

## 技術

- 純靜態網站：`index.html` + `assets/css` + `assets/js`，無需建置。
- 內容與題目全部放在 `assets/js/content.js`，要改字或加題只需改這個檔案。
- 進度以 `localStorage` 儲存，完成 80% 以上算該課達標。
- 影片、樂譜截圖與錄音片段由課堂錄影剪出，放在 `assets/media`（約 8 MB）。

## 資料來源

課堂教學影片（P3 音樂，兩個單元共六節課），畫面為課堂使用的音樂教育平台。網站內容為影片的教學重點整理，供溫習用途。
